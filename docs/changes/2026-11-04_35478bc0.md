# Registro de Cambios: Documentación automática en el mismo commit (`amend`)

## Resumen ejecutivo
Se ha añadido soporte para integrar automáticamente la documentación generada dentro del mismo commit (`amend`), mediante un commit propio o mediante *stage*, evitando dejar archivos pendientes de confirmación. Además, se implementó una variable de entorno para prevenir bucles infinitos de ejecución en el hook de Git al realizar operaciones automáticas.

## Archivos modificados
- `README.md`: Documenta la nueva variable de entorno `GDA_COMMIT_ACTION` y sus valores posibles.
- `scripts/doc_commit.py`: Sustituye la función `auto_stage` por `apply_git_action` para dar soporte a distintos modos de guardado y gestiona la prevención de recursividad mediante `GIT_DOC_AGENT_SKIP`.
- `scripts/install_hook.py`: Actualiza la plantilla del hook `post-commit` para abortar la ejecución si la variable `GIT_DOC_AGENT_SKIP` está activa.

## Detalles técnicos
- **Nueva lógica de acción en Git (`apply_git_action`)**: Se reemplazó la función `auto_stage` por una implementación más flexible que soporta cuatro modos definidos por la variable `GDA_COMMIT_ACTION` o el argumento `--action`:
  - `amend` (por defecto): Realiza un `git commit --amend --no-edit` para adjuntar la documentación al commit recién creado.
  - `commit`: Crea un commit independiente (`docs: auto-document commit <sha>`).
  - `stage`: Solo realiza `git add` sobre el archivo generado.
  - `none`: Ignora las operaciones de Git.
- **Prevención de bucles infinitos en hooks**: Al ejecutar `git commit` o `git commit --amend` desde un hook `post-commit`, el hook vuelve a dispararse en bucle. Para solventarlo:
  - Se inyecta la variable de entorno `GIT_DOC_AGENT_SKIP="1"` en los subprocesos de Git ejecutados por el agente.
  - Se añadió una verificación al inicio del script `doc_commit.py` y en la plantilla del hook (`install_hook.py`) para salir de forma limpia (`exit 0`) si dicha variable está presente.
- **Compatibilidad con CLI existente**: Se mantiene el indicador `--no-stage` en el analizador de argumentos como equivalente a `--action none`.

## Impacto
- **Flujo de trabajo de commits**: Por defecto (`amend`), la documentación generada pasará a formar parte del mismo commit del usuario, manteniendo el historial de Git más limpio al evitar commits secundarios implícitos o cambios de archivos sin hacer commit.
- **Hooks de Git**: Garantiza la estabilidad del sistema al evitar la recursividad infinita del hook `post-commit`.
